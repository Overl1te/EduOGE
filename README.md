## <div id="Особенности">✨ Особенности</div>

### 🎯 Основной функционал

- **🧠 Генератор заданий ОГЭ**
  - Задания формируются автоматически
  - Используются вариации условий с рандомными параметрами
  - Условия и ответы всегда консистентны (никакой магии из воздуха)

- **🔁 Вариативность**
  - Одно задание → десятки вариантов
  - Меняются ограничения, кратности, системы счисления, диапазоны значений

- **📐 Строгое соответствие формату ОГЭ**
  - Формулировки приведены к официальному стилю
  - Формат ввода и вывода как на экзамене
  - В ответе только число, без мусора

- **🧪 Проверка решений**
  - Возможность проверки ответа
  - Потенциал для автопроверки пользовательского кода

### 🛠️ Технические особенности

- **⚙️ Django-бэкенд**
- **📦 Расширяемая архитектура генераторов**
- **📊 Централизованное хранение шаблонов задач**
- **🚀 Подготовка под масштабирование и новые типы заданий**

## <div id="Установка">🚀 Установка</div>

### Системные требования

- **Python 3.10+**
- **Windows / Linux**
- **Git**
- **Мозги (желательно, но не обязательно)**

### Установка из исходников

```bash
git clone https://github.com/Overl1te/EduOGE.git
cd EduOGE
````

#### Создание виртуального окружения

```bash
python -m venv venv

# Windows
venv\Scripts\activate

# Linux / Mac
source venv/bin/activate
```

#### Установка зависимостей

```bash
pip install -r requirements.txt
```

#### Применение миграций

```bash
python manage.py migrate
```

#### Запуск сервера

```bash
python manage.py runserver
```

Или по-человечески:

```bash
start.bat
```

## 🧩 Принципы генерации заданий

* Один шаблон → множество вариантов
* Все числовые параметры:

  * логически связаны
  * укладываются в ограничения
  * гарантируют корректный ответ
* Никаких:

  * отрицательных чисел «по приколу»
  * переполнений
  * ответов «потому что так вышло»
